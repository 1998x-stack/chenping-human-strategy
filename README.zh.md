# 陈平人性谋略

将陈平——汉高祖刘邦麾下顶级谋士，《史记》称"常出奇计，救纷纠之难，振国家之患"——对人性的极致洞察，提炼为10条可复用的行动原则和AI行为指南。

🌐 English | 简体中文

## 解决的问题

大多数人在面对职场政治、商业竞争、人际关系中的复杂博弈时，只能依靠直觉、试错、或者道德说教。他们：
- 直接对抗对手，而不是消除对方的动机
- 诉诸公平和道义，却忘了每个人都在追逐利益
- 试图用实力证明自己，却忽略了认知本身就是可以被设计的
- 对抗人性，而不是顺应和利用人性

## 核心方案

陈平一生所用的计谋，本质上都是对人性弱点的精准狙击。他不相信道德感化，不相信感情羁绊，只相信**利益**和**人性规律**。

本仓库将他的思维体系提炼为三个层次：

| 层次 | 内容 | 用途 |
|------|------|------|
| **info.md** | 深度分析——核心哲学、决策链、经典案例 | 理解陈平的思维体系 |
| **principles.md** | 10条可行动原则——每条附历史原型+底层逻辑+商业应用+职场应用 | 拿来就用 |
| **CLAUDE.md** | AI行为指南——让Claude Code以陈平的思维模式分析问题 | 随时调用 |

## 10条核心原则

| # | 原则 | 一句话 |
|---|------|--------|
| 1 | 利益驱动 | 所有行为的根本解——找到利益，就找到杠杆 |
| 2 | 动机消除 | 不打架，消除对方打架的理由 |
| 3 | 猜忌放大 | 上位者天生怕背叛——喂给他们已经怀疑的东西 |
| 4 | 对比落差 | 控制参照系，就控制了判断 |
| 5 | 侥幸心理 | 人在不确定风险面前，默认选择最乐观的解释 |
| 6 | 枕边风 | 绕过防火墙——通过最信任的人影响决策者 |
| 7 | 妥协隐忍 | 实力不足时，活下来比逞英雄重要 |
| 8 | 自污避祸 | 完美让人恐惧——主动暴露缺陷让人安心 |
| 9 | 以退为进 | 走到顶峰时，唯一安全的方向是退一步 |
| 10 | 结果导向 | 方法服务于目标——但要知道代价 |

## 效果检验

陈平思维框架在起作用的标志：
- 你能看到每个人公开立场背后的真实利益
- 你设计的情境，让别人主动选择了你要的结果
- 你解决冲突的方式是消除动机，而不是升级对抗
- 你能看清权力格局，并在其中安全穿行

## 什么时候不要用

这些原则是为**人性是关键变量的高利害情境**设计的。不要用在：
- 善意和透明已经足够的简单互动中
- 建立在信任基础上的关系——战略计算会摧毁信任
- 不值得付出道德代价的琐碎争端

**权衡：** 这些原则偏向效果而非纯洁。陈平自己临终前说"吾多阴谋，是道家之所禁…终不能复起，以吾多阴祸也。"——用在值得的目标上。
